# Ролики для @vototvet_app: сценарии (часть 2)

Основано на [reels-research.md](reels-research.md). Все ролики 9:16, 7–20 с, работают без звука. Площадки: **Instagram Reels** и **TikTok** (основные), **YouTube Shorts** и **VK Клипы** (зеркала). Один исходник на все четыре.

**Общие правила для всех роликов:**
- Текст хука в верхней трети, ≤ 7 слов, появляется в 1-м кадре.
- В Telegram для съёмки — чистый аккаунт, вымышленные имена и аватары («Тимлид Олег», «Мама», «Заказчик»).
- Демо продукта: набор `@vototvet_app <запрос>` → всплывает список карточек → тап → карточка в чате. Показывать на 100% скорости, не ускорять: это и есть панчлайн.
- Финальный кадр (последние 1,5–2 с): `@vototvet_app` крупно + «напиши в любом чате». Ссылка `t.me/vototvet_app?start=r_…`: Reels и TikTok — в шапке профиля (в подписи «ссылка в профиле»), Shorts — закреплённый комментарий и описание, VK — описание.
- Подпись «сделано в NЁRD» — только в описании, последней строкой.
- «Жёстко» (см. исследование, разд. 5): **острая версия** — карточка видна в кадре чата, без озвучки — для Reels и Shorts; для TikTok — звёздочки (`Отъ*бись`) до проверки модерации; **чистая версия** — стикер «🔞 Hard Mode» поверх карточки — для VK. Мат никогда не попадает в подпись, хештеги, название и на обложку. Из исходника монтируются две версии: со стикером и без.

Состав: 15 сценариев, 5 форматов, 6 групп ответов; «Жёстко» — 4 из 15.

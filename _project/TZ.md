## 1. Суть
Inline-бот для Telegram. В любом чате пишешь `@имябота`, выбираешь ответ («Да.», «Хуйня.», «Иди нахуй.» и т.д.), и в чат уходит красивая карточка-картинка с кнопкой на страницу ответа.
Главный сценарий — рабочие и корпоративные чаты, друзья. Цель MVP — бесплатно проверить, будут ли люди реально это отправлять. Деньги — только во 2-й фазе.

## 2. Что уже есть
- Сайт: https://timmiehub.github.io/otvety/ — 11 ответов, у каждого своя страница `/<slug>/` и превью `/<slug>/og.png` (1200×630).
- Репозиторий: `timmiehub/otvety`, ветка `main`, GitHub Pages из корня.
- Генератор: `_project/gen.py` — все ответы описаны в списке `PAGES` (slug, слово, точка, 2 цвета, фон, тексты). Запуск из корня: `python3 _project/gen.py`, потом `python3 _project/og.py` (нужны playwright и шрифты, путь в переменной `FONTS`).
- Папки с `_` в начале GitHub Pages не публикует, служебное держим там.

## 3. Объём MVP

### 3.1 Inline-режим (главное)
- Пустой запрос `@бот` → показать топ ответов (порядок задаём вручную, потом по популярности).
- Запрос с текстом → поиск по слову ответа и **ключевым словам** (синонимам). Пример: `@бот отказ` → «Нет.», «Отстань.», «Я подумаю.».
- Результат — **фото-карточка** (`InlineQueryResultPhoto`):
  - картинка 1200×630, **JPEG** (Telegram для inline-фото требует JPEG) → генерировать `og.jpg` рядом с `og.png`;
  - подписи нет — картинка говорит сама за себя;
  - кнопки под карточкой: «Открыть ответ» → страница ответа; «Ответить так же» → `switch_inline_query_chosen_chat` (открывает inline в другом чате).
- `cache_time` ~300 с, `is_personal: false`.

### 3.2 Личка с ботом
- `/start` → коротко: что это и как пользоваться (написать `@имябота` в любом чате) + кнопка «Попробовать» (`switch_inline_query`).
- Любое сообщение в личку → то же самое, плюс сетка кнопок с ответами (тап — бот присылает карточку, её можно переслать).

### 3.3 Статистика
- В BotFather включить `/setinlinefeedback` (100%) → ловим `chosen_inline_result`.
- Таблица `events` в Supabase: `id, created_at, type (inline_query | chosen | start), answer_slug, query_text (обрезать до 64), user_hash`. Telegram user_id не хранить, только хеш с солью — данные о пользователях нам не нужны.
- Простой SQL-запрос или view: отправки по дням и топ ответов.

### 3.4 Контент
Довести до ~25 ответов. Уже есть: Да, Нет, Не знаю, Иди нахуй, Может быть, Я подумаю, Ок, Отстань, Похуй, Сам дурак, Хуйня.
Предложение на добавление (утвердить с владельцем перед генерацией):
Согласовано · Не согласовано · Срочно · Позже · Не моя зона ответственности · У меня работает · Это не баг, это фича · Давай созвонимся · Пришли письменно · Красава · Спасибо, не надо · В пятницу не деплоим · Отъебись · Ладно.
Каждому ответу — 3–6 ключевых слов для поиска. Хранить в одном источнике (`_project/answers.json`), чтобы и сайт, и бот брали оттуда; `gen.py` перевести на этот файл.

## 4. Техника
- **Хостинг бота:** Supabase Edge Function (Deno) + webhook. Без отдельного сервера.
- **Библиотека:** grammY (работает в Deno).
- **Секреты:** `BOT_TOKEN`, `WEBHOOK_SECRET` — в секретах Supabase, не в репо. Проверять заголовок `X-Telegram-Bot-Api-Secret-Token` на каждом запросе.
- **Конфиг:** `BASE_URL` (сейчас `https://timmiehub.github.io/otvety/`, после покупки домена — свой). Все ссылки и картинки строятся от него; менять только в одном месте.
- **Данные ответов:** бот берёт `answers.json` с сайта (`BASE_URL/answers.json` — этот файл публикуем) или вшивает при деплое. Лишних запросов на каждый inline-запрос не делать — кешировать в памяти функции.
- Код бота — в этом же репо, папка `_bot/` (не публикуется на Pages).

## 5. Что сделать владельцу (не код)
1. @BotFather → `/newbot` → придумать короткий юзернейм.
2. `/setinline` → включить, плейсхолдер: «Какой ответ?».
3. `/setinlinefeedback` → 100%.
4. `/setdescription`, `/setabouttext`, аватарка.
5. Передать токен **через секреты Supabase**, не в чат.
6. Решить по домену (можно позже — `BASE_URL` меняется в одном месте). Если покупать: Pages → Custom domain + CNAME у регистратора.

## 6. Критерии приёмки
- В любом чате `@бот` показывает список карточек меньше чем за 1 с.
- Поиск находит ответ по синонимам.
- Отправленная карточка — картинка, кнопка «Открыть ответ» ведёт на рабочую страницу.
- `/start` объясняет, как пользоваться, и кнопка «Попробовать» открывает inline.
- Отправки пишутся в `events`; есть запрос «отправки за день / топ ответов».
- Запросы без правильного secret token отбиваются.
- Сайт не сломан: все старые ссылки работают.

## 7. НЕ делаем в MVP
Оплаты, свои ответы пользователей, мини-приложение, мультиязычность, админку.

## 8. Фаза 2 (если MVP зайдёт — смотрим `events` через 1–2 недели)
- **Свой ответ за деньги.** Оплата в ботах за цифровые товары — через Telegram Stars (перед реализацией сверить с актуальными правилами Telegram). Цена ориентир — эквивалент ~100 ₽.
- **Модерация обязательна:** либо свой ответ виден и отправляется только автором, либо премодерация. Иначе пойдут оскорбления конкретных людей и бан бота за жалобы.
- **Конструктор** (слово, подзаголовок, цвет) — в мини-приложении.
- **Свой домен** — короткий и запоминающийся.

# Ролики для @vototvet_app: сценарии (часть 2)

Основано на [reels-research.md](reels-research.md). Все ролики 9:16, 7–20 с, работают без звука. Площадки: **VK Клипы** (основная) + **YouTube Shorts** (зеркало). Instagram — после ответа юриста, TikTok — нет.

**Общие правила для всех роликов:**
- Текст хука в верхней трети, ≤ 7 слов, появляется в 1-м кадре.
- В Telegram для съёмки — чистый аккаунт, вымышленные имена и аватары («Тимлид Олег», «Мама», «Заказчик»).
- Демо продукта: набор `@vototvet_app <запрос>` → всплывает список карточек → тап → карточка в чате. Показывать на 100% скорости, не ускорять: это и есть панчлайн.
- Финальный кадр (последние 1,5–2 с): `@vototvet_app` крупно + «ссылка в описании». Ссылка `t.me/vototvet_app?start=r_…` — в описании, в закрепе (VK) и первым комментарием (Shorts).
- Подпись «сделано в NЁRD» — только в описании, последней строкой.
- «Жёстко»: на экране **всегда** стикер «🔞 Hard Mode» поверх карточки (см. исследование, разд. 5). Слово не видно и не угадывается.

Состав: 15 сценариев, 5 форматов, 6 групп ответов; «Жёстко» — 4 из 15.

### 1 / Пятничный фикс / `r_friday01`
- **Площадки:** VK Клипы, Shorts
- **Формат:** запись экрана

  - 0–3 с — сообщение висит, внизу «Олег печатает…» → приходит второе: «Буквально одна строчка».

  - 12–14 с — финал.
- **Ответ из бота:** «В пятницу не деплоим.» — на 7-й секунде.
- **Финал / CTA:** «Ответ, который спас выходные» → `@vototvet_app`.
- **Подпись:** Отправь тимлиду до 18:00. Ссылка на бота — в описании. #айти #программист #пятница #деплой #рабочийчат

## Топ-3, с которых начать

Почему не «Жёстко» первым: VK может отклонить клип даже со стикером, если модерации что-то не понравится, а новый аккаунт лучше начать без санкций. Жёсткие идут со второй недели, когда будет понятно, как ведёт себя модерация.
